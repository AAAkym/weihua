# 演示用变更分发判定规则（虚构资料，仅供原型演示）

> 虚构规则，用于让原型演示"AI 完成分析、人只做审批"的流程，不代表卫华实际制度。

## 一、变更类型 → 工序影响链

| 变更类型 | 必然涉及（建议下发） | 可能涉及（看变更是否含该工序） | 通常不涉及（建议不下发） |
| --- | --- | --- | --- |
| 板件下料图 / 板材规格变更 | 演示下料甲组、演示下料加工组 | 演示钻孔组（含孔位时）、演示桥架甲组（含组对时） | 涂装、电器、附件、卷筒、小车 |
| 型材 / 筋板变更 | 演示下料乙组 | 演示下料加工组、演示钻孔组 | 涂装、电器 |
| 孔位 / 孔径 / 孔距变更 | 演示钻孔组 | 演示机械加工组、演示下料加工组（需重新下料时） | 涂装、电器、卷筒焊接 |
| 结构安装方式变更 | 演示端梁组 或 演示桥架甲组（按部件） | 演示总装组（总装顺序受影响时） | 涂装、电器、下料 |
| 焊接工艺 / 焊缝坡口变更 | 演示卷筒焊接组（卷筒件）、演示桥架甲组（桥架件）、演示附件乙组（附件件） | 演示机械加工组（焊后加工时） | 涂装、电器、下料 |
| 装配尺寸 / 装配顺序变更 | 演示卷筒装配组、演示小车甲组特种 或 演示小车乙组重型（按部件）、演示总装组 | 演示钻孔组（配作孔时） | 涂装、电器 |
| 电气原理图 / 接线号 / 限位开关变更 | 演示电气甲组 | 演示电气乙组（元件位置或布线受影响时）、演示小车甲组特种（限位安装位置受影响时） | 涂装、下料、卷筒 |
| 元件位置 / 电缆走向变更 | 演示电气乙组 | 演示电气甲组 | 涂装、下料 |
| 涂装体系 / 色号 / 交验要求变更 | 演示涂装甲组（底漆与前处理）、演示涂装戊组（面漆与交验） | — | 结构、下料、电器 |
| 附件清单 / 附件安装变更 | 演示附件甲组 | 演示附件乙组 | 涂装、电器（除附件带电时） |

## 二、判定步骤

1. 逐条读取变更：提取"涉及的部件"和"被改动的工序"（下料 / 钻孔 / 机加 / 焊接 / 装配 / 电气 / 涂装 / 附件 / 总装）。
2. 对每个"未下发"候选班组，查职责总表，看它的工序范围是否与上述工序有交集。
3. 有交集：decision = recommend，理由写清"哪条变更 + 哪个工序 + 该班组职责"。
4. 无交集：decision = skip，理由写清"该班组负责 X，本次变更只涉及 Y，不涉及 X"；不得只写"未提及"。
5. 只有当同一份资料内部矛盾（例如部件标注互相冲突）或关键信息缺失导致无法判断工序归属时，才用 decision = review，并写明缺什么资料。
6. 一张通知单汇总下发：一个班组只出现一次，关联多条变更时合并理由。状态不是"未下发"的班组不产生建议。

## 三、输出要求

- 必须为每一个"未下发"候选班组给出 recommend 或 skip，不允许遗漏；review 应尽量少用。
- 理由不超过两句话，必须能追溯到"变更条目 + 班组职责"。
- 结论只能是建议，最终仍需人工审批，不代替人工决定。
